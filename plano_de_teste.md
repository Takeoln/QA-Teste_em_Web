# Plano de testes para aplicação web

## Objetivo
Validar o funcionamento da aplicação web, verificando se o mesmo possui comportamento esperado sem comprometimentos de suas funções e regras de negócio observáveis.

## Versão
**Versão do plano de testes:** 1.0

**Versão da aplicação:** não informada

## Escopo
**Dentro do escopo**
* Cadastro
* Login
* Lista de desejo

**Fora do escopo**
* Testes automatizados
* Testes de estresse
* Testes de segurança

## Equipe
**Reponsável pelos testes manuais;** Eric

_Como é um projeto a fins de estudo só haverá um integrante na equipe, eu mesmo._

## Riscos
Durante a execução dos testes é possível haver contratempos para a realização dos mesmos, como:
* Instabilidade
* Indisponibilidade
* Falta de funções
* Falta de informações sobre regras de negócio.

Caso houver qualquer contratempo que impeça a realização de um teste, o mesmo pode ser marcado como BLOCKED.
